# From seed to candles

1. **Sample returns at 1 s or 5 s.** A Mulberry32 stream drives Box–Muller normals. A regime is drawn with probabilities 0.52/0.28/0.20 (quiet, volatile, directional); these are _draw_ probabilities, not guaranteed time fractions. The dwell length is sampled between `stateMinimum` and `stateMaximum` minutes. In the directional state a random sign sets the drift.
2. **Make local variability change through time.** The step volatility scale is `baseVolatility / 100 × intensityScale × sqrt(fineSeconds / 60)`. A centered lognormal shock multiplies that scale and the regime multiplier. When `memory` is on, `decay × previousVol + (1 − decay) × newVol` is used. With `fatTail` on, the innovation is Student-t normalized to unit variance (`df > 2`); otherwise it is Gaussian. The Gaussian control preset sets `shock = 0` as well.
3. **Add optional jumps and drift.** Each fine step independently has a jump probability of `jumpProbability / 100 × fineSeconds / 60`; `0.02` means **0.02% per minute**, not 2%. Jump size and trend settings are percent inputs applied to log returns. Returns are synthetic, not fitted to a named asset.
4. **Lock the endpoint if requested.** For `N` returns `rᵢ`, add `(log(end/start) − Σrᵢ) / N` to every return. The last rounded price equals `endPrice` at the configured precision. This is a bridge-style endpoint correction; with regimes, jumps or time-varying volatility it is **not** an exact sampler from a conditioned Brownian motion law. Bounds are tested on the path; a rejected draw consumes random numbers and the next attempt continues on the same stream. No valid draw within the attempt budget is a normal, typed error, not a partially valid result.
5. **Represent one path at multiple resolutions.** Save minute boundaries and extrema before thinning other points. Every output OHLC is derived from the same fine samples. A timestamp between retained points returns a linear interpolation: the compressed path promises minute OHLC, **not** recovery of every discarded one-second tick. Imported OHLC without paths uses an explicit four-point convention (bullish: O–L–H–C, bearish: O–H–L–C).

## Reproducibility

Fix the library version, seed, horizon, `startTime`, prices, precision, bounds, fine step and model. Changing the base bar interval without changing the duration reshapes the same price path; it does not draw a new one. Changing time alone shifts the timestamps of generated candles. Disabling a feature does not change how many random values are consumed per fine step. If the new path changes which attempts pass the bounds, it can still select a different attempt.

`test/compatibility.test.ts` in the library pins hashes of all OHLC rows and stored waypoints for three reference configurations. Other tests cover minute, five-minute, thirty-minute and daily paths, non-divisible resampling, rejection cases and JSON round-trips. These tests protect the current numerical behavior on supported runtimes; they do not assert bit-identical transcendental math across every JS engine or every future release.

## Cost

Simulation is proportional to fine steps × attempts × degrees of freedom. Two floating-point work arrays use roughly `16 × steps` bytes, in addition to output, worker messages and rendering. Long horizons, one-second steps, tight bounds and high volatility can be expensive together. Use a worker in interactive applications; terminating it cancels the run. If an explicit price envelope is too tight, change the scenario or volatility. The generator never silently relaxes a caller's bounds.
